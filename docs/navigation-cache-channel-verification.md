## 实现与边界

- POI 按默认发布路径的事件更新；没有将独立 rules POI 模型静默替换默认逻辑。浏览器特定 loop／vendor 状态在原生端无对应事实，保留适配边界。
- 片段缓存与全片标签缓存独立：绝对 TTL 均为一小时，分别最多 1000／5000 项，各自总预算 512000 个 JSON UTF-16 单元。预算不是 UTF-8 字节数，也不是单响应长度。
- 模块进程独占缓存写入，数据经有界文件描述符传送。清除先递增持久代次，再清两类缓存，旧请求不得重新写回。同步二进制持久化、服务器隔离和严格输入校验是 Android 适配差异；不宣称与 Chrome 存储格式逐字节相同。
- 标签请求只对成功 200 响应的有效块缓存；合法空块可命中，404 和网络失败不缓存为空。按精确 BVID 选择首标签，不把哈希前缀碰撞或后续分类当作当前视频标签。
- 信息流当前首页的绑定及真实正标签绘制已核对。现代路径只接收确切模型、typed aid、普通视频、无广告／直播／番剧冲突；异步回调重新校验模型、持有者、aid、绑定代次。临时 holder 扫描已移除。当前只支持封面模式 0／1；2–5 和更多页面卡片未完成。
