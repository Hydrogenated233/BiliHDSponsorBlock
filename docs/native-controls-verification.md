# 原生播放器控件验证

2026-11-05，NP03J / Android 14 / 哔哩哔哩 HD 2.2.0（2020100），NeoZygisk + Vector，模块仅作用于 HD。以下是单入口阶段的观察记录；后续原生录制按钮、草稿和投稿流程的验证见 `native-marking-verification.md`。多按钮状态会预留更多弹幕输入框空间，下面的单入口坐标属于历史基线。

## 已观察到的结果

- 普通与全屏：倍速前有独立入口，弹幕框收窄以预留位置。普通模式输入框右端 1542、入口 1582–1672、倍速组始于 1682；全屏输入框右端 2339、入口 2379–2469、倍速组始于 2479，均无重叠。
- 默认不显示浮动面板。入口跟随原生控件隐藏；点击后打开面板，返回关闭。普通/全屏切换时重新挂到对应控制栏，恢复旧输入框间距。
- 原生拖动缩略图、时间、进度条和滑块继续工作。普通/全屏均观察到赞助类别显示在原生时间下方；区间外仅显示原生时间，类别清理。
- 自动跳过实测：从约 293.8 秒继续播放至 300.0 秒，随后达到 600.353 秒；显示“已跳过 赞助广告 · 点此撤销”。此轮未执行社区投稿、投票或 viewed 写入。
- 测试视频为公开测试用 BV14741127BN，CID 168885122，时长 1800057 毫秒，返回 9 条社区片段。

预览命中器有 16 项单元用例，加上 6 项协议用例共 22 项：闭区间边界、短片段/POI 最小命中范围、重叠取最短且稳定排序、禁用分类、mute、Full、最小时长、越界与空输入。固定 Chrome 0.17.1 源码的 8 组提取探针也已运行；没有复制其依赖历史缓存导致的漏命中。
