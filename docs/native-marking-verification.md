# HD 原生标记与投稿验证

2026-11-05，NP03J / Android 14 / HD 2.2.0（2020100）/ NeoZygisk + Vector，模块 0.3.0。行为依据 Chrome 扩展 0.17.1 的固定快照 `b3704f380c1614351f5effdc839b8f44e35d1269`。

## 真机通过

- 原生控制栏开始标记，再次点击结束，立即保存区间，不自动弹出编辑器。测试区间为 168.443–229.782 秒，初始分类为“请选择分类”。
- 在 HD 的投稿菜单中编辑分类为赞助广告并保存，宿主保持为 HD。
- 普通预览先跳至开始前两秒乘当前倍率的位置并继续播放；预览操作保存已预览状态。
- 预览结束位置会暂停；两次间隔读取均为 229.782 秒。
- 投稿确认显示视频、CID、服务器及片段。未配置私人 ID 时显示配置提示，保留草稿，未发送投稿。
- 取消正在记录的起点不删除已完成草稿。清除全部标记必须确认；取消确认会保留草稿，确认后清除草稿、未完成起点和预览状态。
- 测试完成后已通过界面清除测试标记。所有测试关闭 viewed 上报，未向社区发送投稿或投票。
- 六个原版 Chrome SVG 已逐字节核对来源并检查发行 APK 资源。真机观察到默认 info/start、记录中的 info/upload/cancel/stop，以及结束后的 info/upload/delete/start；图标变化跟随原有标记状态，测试草稿经界面清除。

## 自动检查与边界

37 项单元测试覆盖协议、草稿约束与版本保护、时间处理和预览分类选择；release 构建与 lint 通过。确认快照为五分钟、不可变且只能消费一次；成功清理同时比较原始草稿和 revision，期间新编辑不会被清掉。

真实服务器投稿成功、未知网络结果、旋转恢复及全部类别 / 动作组合尚未逐项真机验证。单元检查不能替代这些验收。普通/全屏控制栏、社区颜色和原生预览的独立记录见 `native-controls-verification.md`。
